# Content Pipeline Workflow

## Purpose

Turn raw ideas into structured content drafts with a manual review step before publication.

## Flow

```text
Manual Trigger
  → Set Idea
  → Draft Content
  → Create Review Item
  → Notify Reviewer
```

## Portfolio value

Demonstrates human-in-the-loop automation, content pipeline design, and safe publishing boundaries.

## Security

- Does not auto-publish.
- Uses placeholders for APIs and destinations.
- Requires manual approval before any real publishing action.
