# Idea Generator Workflow

## Purpose

Generate structured ideas from a topic list and prepare them for human review.

## Flow

```text
Schedule Trigger
  → Set Topics
  → Generate Idea Draft
  → Format Result
  → Send to Review Destination
```

## Portfolio value

Demonstrates scheduled automation, structured prompts, data transformation, and human-in-the-loop review.

## Security

- Uses placeholder API credentials.
- Does not auto-publish generated content.
- Output should be reviewed manually.
