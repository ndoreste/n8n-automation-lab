# Anonymized n8n Screenshots

This folder contains real n8n workflow screenshots that have been reviewed for public portfolio use and anonymized before publication.

## Current primary screenshots

- `daily-content-pipeline.png` — real anonymized screenshot of a content radar workflow.
- `workflow-design-decisions.png` — real anonymized screenshot of a content publisher workflow.
- `gmail-alert-system.png` — real anonymized screenshot of an alert workflow.

## Security rules

Screenshots in this folder must not expose:

- emails;
- tokens;
- API keys;
- webhook URLs;
- private URLs;
- credentials;
- sensitive IDs;
- personal data;
- customer/client data;
- execution payloads with private information.

## Archive

The `archive/` folder contains earlier SVG recreations used as temporary portfolio placeholders. They are kept only as backup examples and are not the primary screenshots.
