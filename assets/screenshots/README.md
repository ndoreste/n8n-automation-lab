# Anonymized n8n Screenshots

This folder contains portfolio-safe anonymized workflow captures.

Important: the current environment does not expose a live n8n UI, so these files are sanitized visual recreations based on the public example workflow structures, not exports containing private production data.

Before final publication, replace or supplement them with real n8n UI screenshots only after:

- all node names are anonymized;
- credentials are hidden;
- URLs, emails, IDs, and payloads are replaced with placeholders;
- browser tabs and account information are cropped out;
- no execution data or private customer/user data is visible.
